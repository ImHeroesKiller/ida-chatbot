## 2026-08-14 - Embedding Call Latency and Quota Exhaustion Bottleneck
**Learning:** In LLM applications utilizing Retrieval-Augmented Generation (RAG), repetitive user questions and automated test queries repeatedly trigger external API requests to fetch text embeddings (via Gemini's API). Each embedding fetch carries heavy network and processing latency (~300ms to 600ms), which accumulates significantly and risks hitting API quota limit rate limits. An in-memory Map-based cache with simple LRU eviction handles repetitive calls perfectly, reducing cache-hit latency to under 1ms.
**Action:** Always wrap deterministic API/model processing helpers (like embedding generators) in simple, bounds-checked in-memory caches to secure instant responses for redundant pathways and preserve rate limit quota.
